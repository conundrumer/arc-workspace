- An agent's checklist is a read-do checklist with a `+ budget:` line, whose sections are its items: the steps of the agent's work, in order. No entry point includes or inlines it, and the agent receives each item from the step command.
- Of an agent with a checklist, a required step is a step that each run of the agent, or of the conditional part it stands in, takes, and a conditional step or part is one that only the runs that meet a stated condition take.
- Sort each line of its documents: a line that says how to do an act or what is so is reference, and a line that tells the agent to do a thing at a point of its run is an item of its checklist.
- Reference stands under the act or the event it applies to, with no word that orders it among the steps of the run. A step's procedure, how to carry out the acts that step alone does, stands in a file or a section that the step's item links, and no line of the agent's context from its start gives it or has the agent read it. Other reference that a step of every run uses, the facts, the criteria a step's result is judged by and the procedure of an act several steps do, stands in the agent's context from its start, and a conditional part's reference stands in that part's file.
- A required step's item is one line that tells the agent to do the step now, with a link to its reference. This is the form staged disclosure takes for the agent.
- A conditional part's file is one the agent receives only as it enters that part, where its condition holds, and it holds reference alone. The part's items stand as subsections of the checklist item that calls that file, and that item states the condition alone and links the file. The file's editing notes give the state that holds on entering it, and not the condition. This is the form progressive disclosure takes for the agent.
- A step of a conditional part that must come after a later step of the run stands as a conditional step at its point: one item that states the part's condition, tells the agent to do the step, and links that step's reference in the part's file.
- The step command, `uv run python scripts/step.py <agent>`, prints the first item of the checklist, and `uv run python scripts/step.py <agent> <item>` prints the item after `<item>`. For an item that calls a conditional part's file, it prints the condition, the call that enters the part, which prints the file's text and the first item under the call, and the call that skips it. The item after a call's last item is the item after that call, and after the checklist's last item, it prints that the item is the last.
- The agent's entry point has it run the step command at its start, and, once it has done the item that command prints, run it with that item's name. The agent's report is refused until the results of its step calls hold, whole, each item the step command gives from the checklist's first item to its last, with the items of each conditional part the agent entered, each in a result that comes after the last result that holds the item before it. A later round that repeats steps runs again the call that printed the first step it repeats, and, where that call or a later one enters a part whose file the agent's context still holds from an earlier entry, runs `uv run python scripts/step.py <agent> --reenter <item>` in place of `uv run python scripts/step.py <agent> --enter <item>`: `--reenter` prints the part's first item without its file. The agent reads a section an item links once while its context holds that section's text.
- The agent's entry point's spec gives the checklist's path in place of the parts of the agent's work.
- In a review of a change to a checklist or to a conditional part's file, the agent whose checklist it is or links it is a reader of the change, and its context holds the output of each step command it runs.
- A part reaches the agent before the agent meets the part of its work that needs it where it is an item that reaches the agent before its step, a step's procedure that the agent's context from its start gives or has the agent read, or the text of a conditional part that reaches the agent before that part's condition holds.
