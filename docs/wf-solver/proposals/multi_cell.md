# `multi_cell` — a keyed cell set holds more than one cell

The non-singleton test on a keyed cell set: some two distinct cells share the key, and the witness pair projects away. ARC solvers read it to tell an object from a stray dot.

Code form (plain relation; the head keeps the key alone, or a cell of the passing key):

```
multi_cell(Id) :- cell(Id, P), cell(Id, Q), P != Q.
```

Not: a distinct pair both of whose cells flow on, as two marks of one color that feed `same_line`; the other member of a two-member set (`other`); a count against a threshold above two (`Tally`); a disequality that guards a stored map's pair rather than testing a set's size.

Match: two atoms of one relation that share the key column and bind distinct cell variables, with `P != Q` (or the equivalent pair) and at most one of the pair in the head. Coarse grep: `P != Q`; parser matcher at `.scratch/2c737e39/match3.py`.
