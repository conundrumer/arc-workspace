# `Occurrences.covers` — the cells an occurrence lands on

A per-cell readout on `Occurrences`: each placement paired with the grid cells its shape members land on. `occurrence` reports the placement alone, so a caller that paints, tests membership, or measures what an occurrence takes up has to re-join the shape and compose it back at the placement, and a caller whose shape came from a parameter re-reads that parameter in place of the comp's own `shape`. Not: `occurrence` itself (the placement); `placement` (a candidate, before the mismatch test); a stored footprint composed at a mark with no occurrence test behind it.

```
    // The grid cells an occurrence lands on, member by member.
    .decl covers(key: Key, p: Position, p_shape: Position, p_cell: Position)
    covers(Ky, M, S, P) :- occurrence(Ky, M), shape(Ky, S, _), compose(M, S, P).
```

Match: a rule that composes, with `compose`, the instance's `shape` — or the relation that feeds it — at a placement an `Occurrences` instance's `occurrence` produced, deriving the landed cell. The placement reaches that rule directly, or through derived relations, any number of them, including a filter of `occurrence` and a lib comp that selects among candidate placements, as `Slide.rest` and `PlacementPruning.alive` do. Take the forward closure of the instance's `occurrence` over the solver's rules, counting a lib instance's relations as joined to one another, then read each rule in that closure that holds `compose` and check that the composed relation lands no cell outside the shape: the shape itself, a relation that feeds it directly or through further rules, a relation over the shape's cells with substituted values, as 6c434453's `dst` is, or a subset of the shape's feed, as 825aa9e9's `mover_cell` is. Grep `occurrence(` for the instances; run the closure and the check with the parser.
