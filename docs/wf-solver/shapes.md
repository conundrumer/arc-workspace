# Shapes

Controlled vocabulary for solver `// shape:` lines. A shape is a composition property of the task, holding across the file's cases and recorded for corpus-level analysis; what each case teaches stays in `concepts.md`. No line means no listed shape applies.

Terms enter like concepts: reuse an existing term when it fits; add here when none does.

- `latent-canvas` — the body constructs a canvas neither grid fully shows, and the output is determined by that canvas. A canvas is a frame of cells that holds the whole scene in one state.
- `percept-shadow` — the pairs match content by a resemblance no exact map realizes, and the encoded claim is a strictly weaker consequence of it. Two witnesses gate the tag: a pair that breaks the resemblance's exact form while its match still holds, and a configuration the encoded claim accepts and the resemblance rejects
