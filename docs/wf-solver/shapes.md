# Shapes

Controlled vocabulary for solver `// shape:` lines. A shape is a composition property of the task, holding across the file's cases and recorded for corpus-level analysis; what each case teaches stays in `concepts.md`. No line means no listed shape applies.

Terms enter like concepts: reuse an existing term when it fits; add here when none does.

- `latent-canvas` — the work happens on a canvas neither grid fully shows: the body constructs content beyond what the input exhibits, and the output views only part of it
