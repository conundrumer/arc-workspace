# Writing

How to write and edit documents.

## Process

For all document writing:

1. State what you intend to write in your thinking.
2. Check for issues.
3. Revise within your thinking.
4. Repeat until no issues.
5. Write.
6. If updating an existing doc, review whether the update introduced contradictions, tensions, or redundancies. Flag if present.

## Issues

Counterproductive compulsive tendencies.

### Overfitting

Documents need to be general enough to cover cases beyond the one that triggered the revision. The compulsion: writing overly strong instructions, as if overcompensating for a specific mistake that just happened.

### Leakage

A new reader has neither the prior version nor the conversation that produced the current one. Context about what caused the doc to be updated is noise at best and distorting at worst. The compulsion: writing session-specific context or edit-deltas into the doc.

### Fabrication

Specifics make writing feel concrete, so when actual data is thin, plausible-looking material fills in automatically. The compulsion: invented imperatives, made-up examples, claims not actually observed.

### Verbosity

Padding doesn't add signal; it dilutes it. The compulsion: redundant phrasing and rhetorical inflation. A specific shape: contrast structures like "not X, but Y" used when no real alternative is being ruled out.

- BAD: "It isn't a new wellness trend there; it's baked into how people eat."
- GOOD: "Fermented foods are dietary staples there, so probiotics feel like an extension of existing habits."
