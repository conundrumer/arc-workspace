# The arclog lib
- Every type, fact, relation, component and proposer a program can read, other than the rare items.
- A relation is `name(Column: Type, ...)`. A site names one of these columns. `needs` lists the columns an earlier atom of the clause must bind. A relation with no `needs` can enumerate every column.
- A component lists its inputs, then its outputs. Each has a first column `key`, apart from an input marked shared, which every key reads, and the unshared relations of Inclusion and Quotient, whose first column has another name. An input marked from the key holds the key's own values when the instance writes no clause for it, only where the key has one label of each type the input needs. Where the key has two labels of one type, write the clause.

## Types
- `Int`: A signed whole number: it can be below 0. A column that holds a count is declared `Nat`.
- `Nat`: A whole number from 0 up. A `Nat` label fills an `Int` column.
- `Color`: A color.
- `Example`: One example of the task, train or test, in a DET. It is the example's index.
- `Box`: A rectangle of the grid, given by its margin at each edge. A margin below 0 reaches past the edge. `Position` and `Offset` are types under `Box`, and either stands at a Box column. The values of a Box or Position column stand in a frame: the grids that each value is a place in, each grid being the input or the output of the current example, or of the example that an Example column holds. Some lib relations and component outputs make a new frame, which has no grid. [Frames](arclog.md#frames) gives how a column gets its frame.
- `Position`: A Box of one cell. A label at a Box column and a Position column is a Position. A label never stands at a Position column and an Offset column.
- `Offset`: A Box that moves another Box. An Offset column has no frame.
- `Ident`: A label of one thing, such as one object. It holds nothing but the thing's identity. An `Ident` column has one source: the `INIT` form and output that makes it, or the `DET` form of a proposer that makes it. A label stands at `Ident` columns of one source only, so the checker refuses a join, a `NOT`, an `=` or `!=`, a union and a type parameter that meet two sources.
- `C4`: The four turns: D4_ID, D4_CW, D4_HT and D4_CC. A type under `D4`.
- `D4`: The eight symmetries of a square. D4_ID is the identity. D4_CW, D4_HT and D4_CC are the quarter turn clockwise, the half turn and the quarter turn counterclockwise. D4_LR swaps the left and the right (a reflection across the vertical axis), and D4_TB the top and the bottom. D4_DG and D4_AD reflect across the diagonals of those names.
- `Dir`: The four edges of the grid: DIR_T, DIR_B, DIR_L and DIR_R. A type under `Dir8`.
- `DiagDir`: The four corners of the grid: DIAG_TL, DIAG_TR, DIAG_BL and DIAG_BR. A type under `Dir8`.
- `Dir8`: An edge or a corner: a `Dir` or a `DiagDir`.
- `Axis`: AXIS_V, the vertical axis, on which DIR_T and DIR_B lie, and AXIS_H, the horizontal axis, on which DIR_L and DIR_R lie. A type under `Axis4`.
- `DiagAxis`: DAXIS_DG, the diagonal through DIAG_TL and DIAG_BR, and DAXIS_AD, the diagonal through DIAG_TR and DIAG_BL. A type under `Axis4`.
- `Axis4`: An axis or a diagonal: an `Axis` or a `DiagAxis`.
- `Sym`: A symmetry group, a set of D4 elements. SYM_1 is the identity alone, SYM_D4 is all eight, and SYM_C4 is the four turns. SYM_BOX is D4_ID, D4_LR, D4_TB and D4_HT. SYM_X is D4_ID, D4_HT, D4_DG and D4_AD. SYM_LR, SYM_TB, SYM_HT, SYM_DG and SYM_AD each hold the identity and the element they are named after.
- `Sense`: SENSE_CW and SENSE_CC, the two senses of a turn.

## Facts
- `input(P: Position, Col: Color)`: Each cell of the input and its color.
- `ex_input(E: Example, P: Position, Col: Color)`: Each cell of each example's input, train and test. DET only.
- `ex_output(E: Example, P: Position, Col: Color)`: Each cell of each train output. DET only.

## Relations
- `compose(A: Box, B: Box, C: Box)`, needs A B: C is A plus B, margin by margin. With B an offset, C is A moved by B.
- `relative(Base: Box, X: Box, X_rel: Box)`, needs Base X: X_rel is X less Base, margin by margin. For two cells in one frame, X_rel is the offset that moves Base onto X. For a box Base, X_rel is X as a cell of Base's own frame.
- `edge_inset(D: Dir, K: Int, B: Box)`, needs K: The grid with K lines cut from edge D.
- `margin(B: Box, D: Dir, K: Int)`, needs B: K cells lie between B and edge D.
- `apply(D: D4, P: Box, P_out: Box)`, needs P: P_out is P's image when the whole grid undergoes D.
- `corner_dist(P: Box, Diag: DiagDir, K: Int)`, needs P: The sum of P's margins on the two edges of corner Diag.
- `frame_extent(P: Position, A: Axis, N: Int)`, needs P: The grid has N cells along axis A.
- `step_offset(D: Dir8, V: Offset)`: V is one step toward D.
- `sub_extent(P: Position, A: Axis, K: Nat)`, needs P: Each K from 1 to one less than the grid's extent along A.
- `gap(D: Dir8, P: Position, Q: Position, K: Nat)`, needs P Q: Q is ahead of P toward D, on P's line, with K cells strictly between them.
- `divide(T: Nat, Side: Nat, Gap: Int, Part: Nat, Remainder: Nat)`, needs T Side Gap: Along a row of parts of Side cells with Gap cells between each two, the cell T cells from the start is in part Part, Remainder cells into it. Part and Remainder count from 0. A cell in a gap gives no row. T is not tested against an end.
- `dir_elem(D: Dir)`
- `axis_elem(A: Axis)`
- `diag_dir_elem(D: DiagDir)`
- `diag_axis_elem(Da: DiagAxis)`
- `d4_elem(D: D4)`
- `c4_elem(D: C4)`
- `sense_elem(S: Sense)`
- `dir8_elem(D: Dir8)`
- `axis4_elem(A: Axis4)`
- `sym_member(S: Sym, D: D4)`
- `axis_of(D: Dir, A: Axis)`
- `diag_axis_of(D: DiagDir, Da: DiagAxis)`
- `axis4_of(D: Dir8, A: Axis4)`
- `corner_dir(C: DiagDir, A: Axis, D: Dir)`: Corner C's edge on axis A is D.
- `opposite(D: Dir, Opp: Dir)`
- `diag_opposite(D: DiagDir, Opp: DiagDir)`
- `dir8_opposite(D: Dir8, D2: Dir8)`
- `perp(A: Axis, A2: Axis)`
- `diag_perp(Da: DiagAxis, Da2: DiagAxis)`
- `turn(S: Sense, D: Dir, D2: Dir)`: A quarter turn in sense S takes D to D2.
- `c4_turn(S: Sense, T: C4)`: T is the quarter turn in sense S.
- `reflection(A: Axis4, T: D4)`: T is the reflection across the line along A.
- `axis_inversion(A: Axis4, T: D4)`: T is the reflection that swaps the two directions on A and keeps the other two.
- `d4_compose(A: D4, B: D4, C: D4)`: C is B, then A.
- `inside(A: Box, B: Box)`, needs A B: A lies in B, its sides included.
- `interior(A: Box, B: Box)`, needs A B: A lies in B and touches none of B's sides.
- `same_dist(D: Dir, P1: Box, P2: Box)`, needs P1 P2: P1 and P2 have the same margin on edge D.
- `same_line(A: Axis4, P: Box, Q: Box)`, needs P Q: P and Q are on one line along A: a column, a row, or a diagonal.
- `same_corner(D: DiagDir, P1: Box, P2: Box)`, needs P1 P2: P1 and P2 have the same margins on both edges of corner D.
- `nearer(D: Dir8, P: Box, Q: Box)`, needs P Q: P is strictly nearer edge D than Q is. For a corner, the distances compared are `corner_dist`.
- `centered(P: Box)`, needs P: P's two margins on each axis are equal. On an axis of even extent, no cell is centered.
- `dist_pair(P: Box, D: Dir, K: Int, K2: Int)`, needs P: P's margins on edge D (K) and on the opposite edge (K2).
- `diag_dist(P: Box, Diag: DiagDir, A: Axis, K1: Int, K2: Int)`, needs P: P's margin K1 on the edge of corner Diag that lies on axis A, and K2 on the corner's other edge.
- `axis_extents(P: Position, A: Axis, N1: Int, N2: Int)`, needs P: The grid's extent along A (N1) and along the other axis (N2).
- `box_extent(B: Box, P: Position, A: Axis, N: Int)`, needs B P: B is N cells long along A. P is any cell of the grid, and gives only the grid's extent.
- `axis_inset(D: Dir, K1: Int, K2: Int, B: Box)`, needs K1 K2: The grid with K1 lines cut from edge D and K2 from the opposite edge.
- `uniform_inset(K: Int, B: Box)`, needs K: The grid with K lines cut from every edge.
- `uniform_outset(K: Int, B: Box)`, needs K: The grid with K lines added past every edge.
- `jump(P: Box, D: Dir8, K: Int, Q: Box)`, needs P K: Q is K steps from P toward D. Q can lie off the grid.
- `jump_offset(D: Dir8, K: Int, V: Offset)`, needs K: V is K steps toward D.
- `neighbor(P: Box, D: Dir8, Q: Box)`, needs P: Q is one step from P toward D. Q can lie off the grid.
- `split(P: Box, A: Axis, Along: Box, Across: Box)`, needs P: Along has P's margins on axis A and 0 on the other axis, so for A = AXIS_V it is P's whole row, and for A = AXIS_H P's whole column. Across is P less Along.
- `perp_dir(D: Dir, D2: Dir)`: D2 is an edge on the other axis from D.
- `diag_dirs(D: DiagDir, A: Axis, D1: Dir, D2: Dir)`: Corner D's edge on axis A is D1, and its edge on the other axis is D2.
- `apply_dir(D: D4, Dir: Dir, Dir_out: Dir)`
- `apply_diag_dir(D: D4, Dir: DiagDir, Dir_out: DiagDir)`

## Components
- **Cardinality**<Key, Member> (construction): The count of each key's members.
    - in `member(key: Key, m: Member)`
    - in `domain(key: Key)`, from the key: the keys to count. A key with no member counts 0.
    - out `size(key: Key, N: Nat)`
- **Excess**<Key, Member> (construction): For each key, how many more members the plus set has than the minus set, where that is more than 0.
    - in `plus(key: Key, m: Member)`
    - in `minus(key: Key, m: Member)`
    - out `excess(key: Key, N: Nat)`
- **Singleton**<Key, Val> (construction): The one value of each key's members.
    - in `member(key: Key, v: Val)`
    - out `value(key: Key, v: Val)`: the value, where every member has it.
    - out `plural(key: Key)`: the members have more than one value.
- **Inclusion**<Key, Pat, Member> (construction): Each observed set against each pattern set, by their members.
    - in `pattern(pattern: Pat, m: Member)`, shared
    - in `observed(observed: Key, m: Member)`
    - out `superset(observed: Key, pattern: Pat)`: the observed set holds every member of the pattern.
    - out `equal(observed: Key, pattern: Pat)`: the two sets have the same members.
    - A pair of sets that share no member has no row.
- **Quotient**<T> (construction): One label per class of an equivalence. A row of `equivalent` or `edge` puts a and b in one class, and the classes are closed over chains of rows.
    - in `equivalent(a: T, b: T)`, shared
    - in `edge(a: T, b: T)`, shared
    - out `class(a: T, Id: Ident)`: a's class. An element in neither input has no class; `equivalent(a, a)` gives it a class of its own.
- **Order**<Key, T> (construction): Each member's rank, from a strict order or from a score.
    - in `member(key: Key, t: T)`
    - in `before(key: Key, a: T, b: T)`: a comes before b, for every such pair and not only neighbors, and never a before a.
    - in `score(key: Key, t: T, S: Int)`: a number per member. A lower score comes first, and equal scores tie.
    - in `secondary_score(key: Key, t: T, S: Int)`: a number that orders the members within each tie of `score`. A member with a `score` and no `secondary_score` comes before the members of its tie that have one.
    - in `probe(key: Key, t: T)`: an element ranked against the members, and not counted among them. It takes its place from its own `score` or `before` rows.
    - out `rank(key: Key, t: T, R: Nat)`: R members come before t, so the first has rank 0. Ties share a rank, and the next rank counts every tied member: scores 1, 1, 2 give ranks 0, 0, 2.
    - out `dual_rank(key: Key, t: T, R: Nat)`: R members come after t.
    - out `minimal(key: Key, t: T)`: the members nothing comes before. Under a tie, every tied member.
    - out `maximal(key: Key, t: T)`: the members nothing comes after. Under a tie, every tied member.
    - out `successor(key: Key, a: T, b: T)`: b comes next after a. Under ties, each member of one score level is followed by each member of the next, and tied members don't follow each other.
    - out `cyclic_successor(key: Key, a: T, b: T)`: `successor`, with the first after the last.
    - Give `before`, or `score` with `secondary_score`, not both. A key with both, or with two `score` rows or two `secondary_score` rows for one member, has no output.
    - A member with no `score` row is related to no member: it has rank 0 and dual rank 0, and it is minimal and maximal.
- **Walk**<Key, T> (construction): The member a count of steps along a successor relation reaches.
    - in `successor(key: Key, p: T, p_next: T)`
    - in `steps(key: Key, N: Int)`
    - out `walk(key: Key, p0: T, N: Nat, p: T)`: N steps from p0 reach p, for every N from 0 to the greatest N of `steps`. A walk starts only at a member that has a successor, and a walk that runs out of successors has no row past its end.
- **Propagation**<Key, Node> (construction): The nodes reached by forward chaining.
    - in `source(key: Key, n: Node)`, from the key: the nodes reached at the start.
    - in `edge(key: Key, a: Node, b: Node)`: b is reached once a is.
    - in `join(key: Key, a: Node, b: Node, c: Node)`
    - out `reached(key: Key, n: Node)`
- **Distance**<Key, Node> (construction): The least cost from a source to each node of a graph.
    - in `edge(key: Key, a: Node, b: Node)`: a step from a to b, of cost 1.
    - in `weight(key: Key, a: Node, b: Node, W: Int)`: a step from a to b, of cost W.
    - in `source(key: Key, n: Node)`, from the key: a node at cost 0.
    - in `source_distance(key: Key, n: Node, K: Int)`: a node at start cost K.
    - out `distance(key: Key, n: Node, K: Int)`
    - out `predecessor(key: Key, b: Node, a: Node)`
- **Enclosure**<Key> (construction): The parts of a cell set that no walk through the set reaches from the grid's edge. The walk starts at the set's cells on the grid's edge and takes the four cardinal steps.
    - in `cell(key: Key, P: Position)`
    - out `enclosed(key: Key, P: Position, Id: Ident)`: each enclosed part under its own label.
- **Boundary**<Key> (construction): The cells of a set that face out of it.
    - in `cell(key: Key, P: Position)`
    - in `dir(D: Dir8)`, shared, default DIR_T, DIR_B, DIR_L, DIR_R
    - out `boundary(key: Key, P: Position)`: P is exposed toward some direction.
    - out `exposed(key: Key, P: Position, D: Dir8)`: no cell of the set lies one step from P toward D. Off the grid counts as no cell.
- **BoundingBox**<Key, Point under Box> (construction): The least box that holds a set.
    - in `cell(key: Key, P: Point)`, from the key
    - out `box(key: Key, B: Box)`
- **Agreement**<Key, Val> (construction): Two valued cell sets compared under D4 transforms.
    - in `source(key: Key, P: Box, v: Val)`
    - in `target(key: Key, P: Box, v: Val)`
    - in `transform(D: D4)`, shared, default D4_ID, D4_CW, D4_HT, D4_CC, D4_LR, D4_TB, D4_DG, D4_AD
    - out `mismatch(key: Key, D: D4)`: D is in `transform`, and for some source cell P, the cell `apply` of D to P gives is not a target cell of P's value: no target cell is there, or one of another value.
    - out `conflict(key: Key, D: D4)`: for some source cell, its image is a target cell of another value. A missing target cell is no conflict.
    - A D in `transform` with no `mismatch` row takes the source into the target. Target cells that are no source cell's image are not tested.
- **Tiling**<Key> (construction): A frame built from copies of an inner frame at outer positions.
    - in `outer(key: Key, P: Position)`: the frame of copies.
    - in `inner(key: Key, P: Position)`: the frame of one copy.
    - in `gap(key: Key, A: Axis, G: Int)`: G cells between each two copies along A. An axis with no row has gap 0.
    - out `cell(key: Key, P_outer: Position, P_inner: Position, P: Position)`: P is the cell P_inner of the copy at P_outer.
- **Frame**<Key> (construction): The cells of a frame of given extents.
    - in `extent(key: Key, A: Axis, N: Int)`, from the key: N cells along A. An axis with no row has extent 1 where the other axis has a row. A key with no row on either axis has no cell.
    - out `cell(key: Key, P: Position)`
- **Outlines**<Key>: The rectangles drawn in a cell set.
    - in `node(key: Key, P: Position)`
    - out `box(key: Key, B: Box)`: every cell of B's outline is in the set. B is at least two cells long on each axis, and its interior may hold any cells.
- **Occurrences**<Key, Val>: Where a shape appears among valued cells.
    - in `cell(key: Key, P: Position, v: Val)`
    - in `shape(key: Key, P: Box, v: Val)`
    - in `transform(D: D4)`, shared, default D4_ID
    - out `candidate(key: Key, D: D4, P: Box)`: P is an offset, and D is in `transform`. For at least one shape cell S of value v, the cell that `apply` of D to S, then `compose` with P, gives is a `cell` row of value v. Every occurrence is a candidate.
    - out `occurrence(key: Key, D: D4, P: Box)`: as `candidate`, for every shape cell S of value v. P moves the D-image of the shape onto the cells.
    - Only the cells `cell` holds count.
- **Periods**<Key, Val>: The translations along an axis that leave valued cells unchanged.
    - in `cell(key: Key, P: Position, v: Val)`
    - out `period(key: Key, A: Axis, K: Nat)`: a move of K along A takes every cell onto a cell of the same value, wherever both cells exist. K runs from 1 to one less than the extent. A K with no pair of cells to compare is a period.
    - out `fundamental_period(key: Key, A: Axis, K: Nat)`: the least period along A that compares at least one pair of cells.
    - out `approximate_period(key: Key, A: Axis, K: Nat)`: a period read through damage: the line pairs the move breaks do not outnumber those it keeps.
- **Flood**<Key> (construction): The cells a walk through the set reaches from a source.
    - in `node(key: Key, P: Position)`
    - in `source(key: Key, P: Position)`, from the key
    - in `step(Delta: Offset)`, shared, default rows: the steps that join two cells. The default is the four cardinal steps.
    - out `reached(key: Key, P: Position)`
    - A source outside `node` reaches nothing.
- **CellDistance**<Key> (construction): The fewest steps through the set from a source to each cell.
    - in `node(key: Key, P: Position)`
    - in `source(key: Key, P: Position)`
    - in `step(Delta: Offset)`, shared, default rows: as in `Flood`.
    - out `distance(key: Key, P: Position, K: Nat)`: K steps from the nearest source reach P. A source is at 0. A source outside `node` is at 0 and reaches nothing.
    - out `predecessor(key: Key, Q: Position, P: Position)`
- **Connectivity**<Key> (construction): The connected pieces of a cell set.
    - in `node(key: Key, P: Position)`
    - in `step(Delta: Offset)`, shared, default rows: as in `Flood`. To join cells that touch at a corner too, the clause gives all eight steps.
    - out `component(key: Key, P: Position, Id: Ident)`
    - out `adjacent(key: Key, P: Position, Q: Position)`
- **Ray**<Key, Point under Box> (construction): The straight path from a source toward a direction.
    - in `source(key: Key, P: Point)`: where each path starts. A source on the grid and outside `node` gives only its own row at K = 0.
    - in `node(key: Key, P: Point)`: the cells a path may step onto. A path stops before its first step off them.
    - in `dir(key: Key, D: Dir8)`, from the key
    - out `ray(key: Key, P: Point, D: Dir8, K: Nat, Origin: Point)`: P is K steps from Origin toward D. Each source is on its own path at K = 0.
    - out `end(key: Key, P: Point, D: Dir8, K: Nat, Origin: Point)`: the path's last cell.
- **Division**<Key> (construction): The frame cut into equal parts on each axis.
    - in `cell(key: Key, P: Position)`
    - in `parts(key: Key, A: Axis, N: Int)`: N parts along A.
    - in `side(key: Key, A: Axis, K: Int)`: parts of K cells along A, in place of `parts`. An axis with neither is one part.
    - in `gap(key: Key, A: Axis, G: Int)`: G cells between each two parts along A. An axis with no row has gap 0.
    - out `tile(key: Key, P: Position, P_outer: Position, P_inner: Position)`: P is the cell P_inner of the part at P_outer. P_outer is a cell of the frame of parts.
    - A cell in a gap, or in a leftover shorter than a part, has no row. Where the parts and gaps don't fill an extent exactly, no cell has a row.

## Proposers
- "Every input" counts the test inputs too. "Every train output" counts the train outputs only.
- A domain gives every value of its column's type that the grids it reads admit. In a DET, as in `(DET &a AxisDomain)`, it reads every grid of the task: the train inputs, the train outputs and the test inputs. `&a` is one axis, not the set of axes, and a pair domain's DET holds one pair at each assignment. In a RULE, as in `(RULE &a AxisDomain)`, a domain reads the input of each example alone and holds every value at once, one row each: `&a` is AXIS_V and AXIS_H. `ColorDomain` gives the colors of that input, and `NumberDomain` the numbers from 0 to that input's largest extent.
- A clause names a domain as its proposer. A body atom can't read one: write `(RULE &a AxisDomain)`, then read `&a`.
- `AxisDomain(A)`
- `ColorDomain(C)`
- `D4Domain(D)`
- `DiagAxisDomain(Da)`
- `DiagDirDomain(D)`
- `DirDomain(D)`
- `NumberDomain(N)`
- `SenseDomain(S)`
- `SymDomain(S)`
- `SharedColor(C)`: A color in every input.
- `DominantColor(C)`: A color with the most cells in every input.
- `RarestColor(C)`: A color with the fewest cells in every input.
- `AnyOutNewColor(C)`: A color in some train output and no input.
- `VanishedColor(C)`: A color in every input and no train output.
- `ChangedColor(C)`: A color that every one of its cells loses in the output, each input cell compared with the output cell at the same place. Where a pair's input and output differ in size, a cell outside the smaller grid keeps no color.
- `UnchangedColor(C)`: A color that every one of its cells keeps in the output, the cells compared as `ChangedColor` compares them.
- `ScaleRatio(K)`: Along some axis, each output extent is K times its input extent. K can be 1.
- `DivisorRatio(K)`: Along some axis, each input extent is K times its output extent.
- `ConstInDim(N)`: An extent of every input.
- `ConstOutDim(N)`: An extent of every train output.
- `ConstOutDimAxis(A, N)`: An extent of every train output, with its axis.
- `TileCount(N)`: N tiles, with a gap of 0 to 3 between each two, fill an axis of every input. N is 2 to 8. `TileDim` is found apart, so an N and a D need not come from one tiling.
- `TileDim(D)`: Tiles of D cells, with a gap of 0 to 3 between each two, fill an axis of every input. There are 2 to 8 tiles.
- `SepTileCount(N)`: Along some axis, N parts fill the axis, with G lines between each two. Each line in a gap holds one color, the same in every input. N is 2 to 8, and G is 1 to 3. The lines are rows along AXIS_V, columns along AXIS_H.
- `SepTileCountAxis(A, N)`: `SepTileCount`'s N with its axis A, and also the other axis with N = 1 where no input has such a tiling on it.
- `SepThickness(G)`: The G of `SepTileCount`: the number of lines between each two parts.
- `TileD4(Pt, T)`: In every pair, the output is a whole number of input-sized copies along each axis, and is not the input's size. Pt is a copy's place in the frame of copies, and the copy at Pt is the input under T. A T that swaps the axes is tried only for a square input. A Pt has several rows where the input is symmetric.
- `PanelCombine(Id, C_out, P, C)`: The input is two panels of the output's size along one axis, with any number of separator lines between. Each output cell has the cell at the same place in each panel. An entry Id has two rows, one per panel, that share C_out: P is the panel's place as a cell of the frame of two parts along that axis, C is the color of that panel's cell, and C_out is the output cell's color. There is one entry per combination of the two panel colors and the output color in the train pairs.
