# The arclog lib: rare items

## Types
- `number`: Another spelling of `Int`.
- `Unit`: The type of a value with no fields. An arcdata `param` form may name it. No lib relation has a `Unit` column.

## Relations
- `tile_size(Ext: Nat, N: Nat, G: Int, K: Nat)`, needs Ext N G, or K N G: N tiles of K cells, with G cells between each two, fill Ext cells exactly: K is Ext less the N - 1 gaps, divided by N. A row stands only where that difference is positive and N divides it evenly.
- `sym_elem(S: Sym)`
- `d4_inverse(D: D4, D_inv: D4)`
- `d4_identity(D: D4)`
- `pose_difference(A: Pose, B: Pose, D: D4)`: A and B are poses of one `RIGID_DET` assembly, each a placement of it. D takes the placement at pose A onto the placement at pose B.
- `same_slab(D: Dir, P1: Box, P2: Box)`, needs P1 P2: P1 and P2 have the same margin on edge D, and the same two margins on the other axis.
- `corner_inset(Diag: DiagDir, K: Int, B: Box)`, needs K: The grid with K lines cut from each edge of corner Diag.
- `edge_outset(D: Dir, K: Int, B: Box)`, needs K: The grid with K lines added past edge D.
- `corner_outset(Diag: DiagDir, K: Int, B: Box)`, needs K: The grid with K lines added past each edge of corner Diag.
- `axis_outset(D: Dir, K1: Int, K2: Int, B: Box)`, needs K1 K2: The grid with K1 lines added past edge D and K2 past the opposite edge.
- `frame_offset(P: Position, A: Axis, K: Nat, V: Offset)`, needs P: V is K steps along A, for each K that `sub_extent` gives. Each K has two rows, one toward each edge of A.
- `apply_dir8(D: D4, Dir: Dir8, Dir_out: Dir8)`

## Components
- **Unfold**<Key, T, Item> (construction): The items taken and left at each state of a walk over states.
    - in `start(key: Key, t: T)`
    - in `initial_taken(key: Key, item: Item)`
    - in `initial_untaken(key: Key, item: Item)`
    - in `conflict(key: Key, item: Item, item2: Item)`: when item is taken, item2 leaves the untaken items without being taken.
    - in `score(key: Key, t: T, item: Item, S: Int)`: with a score, the item taken at a state is the untaken item of least score.
    - in `step(key: Key, t: T, t2: T)`, may read the outputs: a step from t to t2 takes one item.
    - in `skip(key: Key, t: T, t2: T)`, may read the outputs: a step from t to t2 takes none.
    - in `take(key: Key, t: T, item: Item)`, may read the outputs
    - out `taken(key: Key, t: T, item: Item)`
    - out `untaken(key: Key, t: T, item: Item)`
    - out `excluded(key: Key, t: T, item: Item)`
    - out `take(key: Key, t: T, item: Item)`
    - The input `take` is the item taken at t. The output `take` has a row where `score` gives it.
    - With `score`, a tie forks the walk. An item taken on one branch and left on another is in both `taken` and `untaken` at a state both branches reach.
- **ExtentDivisions**<Key>: The equal divisions a frame's extent admits.
    - in `frame(key: Key, P: Position)`
    - out `division(key: Key, A: Axis, N: Nat, K: Nat, G: Int)`: along A, N parts of K cells with G cells between each two fill the extent exactly. N is 2 or more and K is 1 or more. G can be less than 0, down to 1 less K: then two neighboring parts share that many lines.
- **Wallpaper**<Key, Val>: The symmetries of a periodic valued pattern.
    - in `transform(D: D4)`, shared: the D4 elements to test. It has no default.
    - in `cell(key: Key, P: Position, v: Val)`: the pattern's cells.
    - in `grid(key: Key, P: Position)`: the frame's cells.
    - in `period(key: Key, A: Axis, K: Int)`: the pattern's period along A, at most one per axis, more than 0. An axis with no row has none. A key with two periods on an axis, or a period of 0, has no output.
    - out `symmetry(key: Key, D: D4, Delta: Offset)`: D, then the shift Delta, takes some cell onto another cell and no cell onto a cell of another value. Cells outside `grid` are ignored. One D has a row for each shift that differs by a multiple of the period and lands in the frame. Delta is 0 on an axis with no period. So the identity has a row only where a period exists.
    - out `action(key: Key, P: Position, Q: Position)`: a symmetry or a period move takes the frame cell P onto the frame cell Q.
    - A key with no row in `transform` and none in `period`, or none in `cell` and none in `period`, has no output.
- **DemonstrationConsistency**<Key, Demonstrated, Object, Index, Value>: The rules a demonstrated pair confirms. An input of a nested task holds pairs that demonstrate a rule, and an object that the same rule completes.
    - in `value(key: Key, o: Object, i: Index, v: Value)`: object o holds v at index i.
    - in `prediction(key: Key, c: Demonstrated, o: Object, i: Index, v: Value)`: rule c predicts that the object paired with o holds v at i.
    - in `demonstration(key: Key, o: Object, o2: Object)`: a demonstrated pair, o and its partner o2.
    - out `counterexample(key: Key, c: Demonstrated, o: Object, o2: Object)`: c's prediction for o is not o2.
    - out `consistent(key: Key, c: Demonstrated, o: Object, o2: Object)`: c's prediction for o is o2.
    - out `unconfirmed(key: Key, c: Demonstrated)`: c fails some demonstrated pair.
    - out `confirmed(key: Key, c: Demonstrated)`: c predicts every demonstrated pair.
    - A prediction holds every index of the object it predicts. An index it leaves out counts as one that object lacks.
    - A rule that predicts nothing for any object is in neither.

## Proposers
- `ColorColorDomain(C_from, C_to)`
- `DiagDirAxisDomain(D, A)`
- `NumberDirDomain(N, D)`
- `OutNewColor(C)`: A color in every train output and no input.
- `ChangedPairs(C_from, C_to)`: A color map: each cell that changes gives its input color and its output color.
- `VanishedNewPairs(C_from, C_to)`: A color map read off whole examples: each input color an output lacks, with each output color its input lacks.
- `ScaleRatioAxis(A, K)`: As `ScaleRatio`, with its axis A.
- `DivisorRatioAxis(A, K)`: As `DivisorRatio`, with its axis A.
- `DimDiff(D)`: Along some axis, each output extent differs from its input extent by D, more or less.
- `ConstInDimAxis(A, N)`: An extent of every input, with its axis.
- `Period(K)`: On each axis, the least move under which every input repeats. An axis with no common period gives none.
- `SepTileDim(D)`: As `SepTileCount`, with parts of D cells in place of N parts.
- `CountRankAsc(C, R)`: The colors of the inputs ranked by cell count: R colors have fewer cells than C. Ties share a rank, and a row is kept only where every input gives it.
- `CountRankDesc(C, R)`: As `CountRankAsc`, with R the number of colors that have more cells than C.
